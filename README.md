# OPTCG Judge Trainer

An unofficial, offline-capable study tool for One Piece Card Game judges and players:
source-checked rules questions, timed mock exams, the official Q&A as a drill, and a card
library with the official card text and published errata.

**Open it:** https://shocco.github.io/optcg-judge-trainer/ — a single page that runs
in the browser. Progress is saved only in your browser's local storage.

**Change log:** https://shocco.github.io/optcg-judge-trainer/changelog.html lists what changed in
each public version. The current version is shown in the page footer.

## Sources

- Card stats and effect text: the official English card list
  (https://en.onepiece-cardgame.com/cardlist/), captured 2026-10-19.
- Rules, FAQ and errata: the official comprehensive rules, FAQ and errata documents; every
  question cites the document, page and revision it was checked against.
- Card images are **not** hosted here. Pictures load from optcgapi.com (which serves the
  official card images), and each card also links to its image and card-list page on the
  official site.

Questions were written and checked against the cited sources but have not been reviewed by
an official judge program. Always confirm rulings with the current official documents.
